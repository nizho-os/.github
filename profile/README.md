# Nizho

A desktop Linux where privacy settings are on by default, built on an immutable (bootc) base.

**Status: developer preview, not released.** Nothing here is ready for everyday use yet, and it has only been tested in virtual machines and on one laptop.

- [nizho](https://github.com/nizho-os/nizho): the operating system image and its source.

Nizho was previously called ArkaOS.

# Nizho OS

Nizho is a desktop Linux operating system where privacy settings are on by default, built on an immutable (bootc) base. Updates arrive as whole system images, and the previous image is kept so the computer can go back to it.

**Status: developer preview, not released.** Nothing here is ready for everyday use yet, and it has only been tested in virtual machines and on one laptop.

## Projects

- [nizho](https://github.com/nizho-os/nizho): the operating system image and its source.
- [archon](https://github.com/nizho-os/archon): a security-monitored, AUR-aware package manager for Arch Linux.
